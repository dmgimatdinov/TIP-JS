# Демонстрация к Лекции № 4

Пример показывает, как те же операции над списком тем, что и в Лекции 2, реализуются средствами React: состояние описывается через `useState`, побочные эффекты — через `useEffect`, а DOM React обновляет сам, сравнивая предыдущее и следующее дерево.

[К конспекту лекции](../README.md) · [К описанию курса](../../../README.md)

## Запуск

Из этого каталога:

```bash
npm start
```

После запуска необходимо открыть:

```text
http://127.0.0.1:5504/
```

Зависимости устанавливать не требуется. React и ReactDOM подключаются как ES-модули с CDN, а JSX компилируется в браузере через Babel Standalone. Для проверки синтаксиса сервера:

```bash
npm run check
```

## Состав примера

| Файл | Назначение |
|---|---|
| `index.html` | Корневая страница с `#root` и подключением React, ReactDOM и Babel. |
| `app.jsx` | Один файл со всеми компонентами, хуком `useTaskData` и имитацией API. |
| `styles.css` | Оформление, аналогичное демо Лекции 2 для сопоставления. |
| `serve.mjs` | Локальный HTTP-сервер на стандартных модулях Node.js. |
| `package.json` | Команды запуска и проверки. |

## Что показывает пример

- функциональные компоненты и `props`;
- `useState` для состояния и иммутабельные обновления массива задач;
- `useEffect` для загрузки данных при монтировании и очистки при размонтировании;
- управляемую форму создания и редактирования;
- списки с обязательным `key`;
- производную выборку по фильтру без отдельного состояния;
- состояния `loading`, `ready`, `empty` и сохранение в `localStorage`.

Демонстрационный пример показывает архитектурный принцип, но не является готовым решением ПР7 или ПР8: предметная область, контракты функций, структура модулей и проверяемые требования практических работ отличаются.
